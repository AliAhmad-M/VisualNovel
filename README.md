# Blackwood
The code repository for a Visual Novel game named Blackwood made using the Godot Engine. The game is a murder mystery where your choices impact the story and 
you must make the correct choices to solve the mystery of the Blackwood mansion. The game can be downloaded at the link: [https://blaze-glitch.itch.io/blackwood-demo/](https://blaze-glitch.itch.io/blackwood-demo/)
